# 「毎月自動更新」の仕組みについて

このサイトには、御所市観光ホームページの新着情報を毎月自動で取り込む仕組みを組み込んでいます。GitHub Pages は静的サイトのみをホストするため、更新処理そのものは **GitHub Actions**（GitHubが無料で提供する自動実行の仕組み）が担当します。

## 全体の流れ

1. 毎月1回（UTC 18:00 = 日本時間 深夜3時ごろ）、GitHub Actions が自動で起動します。
2. `scripts/update-news.mjs` が御所市観光ホームページの新着情報一覧
   （`https://www.city.gose.nara.jp/kankou/news/0001.html`）を取得し、
   最新のお知らせを `news.json` に書き出します。
3. 内容に変化があれば、その変更を自動でリポジトリにコミット・プッシュします。
4. GitHub Pages が自動的に再デプロイし、サイトの「最新情報」欄に反映されます。

サイト側（`index.html`）は表示のたびに `news.json` を読み込んでいるだけなので、
上記の裏側の更新さえ回っていれば、手作業は一切不要です。

## 必要なファイル

リポジトリの直下に、次の構成でファイルを置いてください。

```
your-repo/
├── index.html
├── news.json
├── scripts/
│   └── update-news.mjs
└── .github/
    └── workflows/
        └── update-news.yml
```

## 有効にするための設定（最初の1回だけ）

1. 上記のファイルをそのままリポジトリにコミット・プッシュします。
2. GitHubのリポジトリ画面で **Settings → Actions → General** を開き、
   「Workflow permissions」を **Read and write permissions** に設定します
   （自動コミットにはこの権限が必要です）。
3. **Actions** タブを開くと `Monthly news refresh` というワークフローが
   表示されます。初回は `Run workflow` ボタンから手動で一度実行し、
   `news.json` が正しく更新されるか確認することをおすすめします。
4. 以降は毎月自動で実行されます。

## サイトの構造が変わって取得できなくなったら

御所市サイトのHTML構造が将来変わると、`update-news.mjs` の解析がうまく
働かなくなる可能性があります。その場合はワークフローが「安全に何もせず終了」
する設計にしてあるので、サイトが壊れることはありません（`news.json` は
直前の内容のまま残ります）。取得できなくなった場合は、御所市の新着情報
ページのHTML構造を見て `scripts/update-news.mjs` 内の正規表現を調整して
ください。

## 言語切り替えについて

`index.html` は英語・日本語の両方のテキストを1つのファイルに含んでいて、
右上（およびフッター）の「EN / 日本語」ボタンで切り替わります。切り替え
状態はURLの `#en` / `#ja` に保存されるだけなので、ブラウザの保存機能
（localStorage等）は使っていません。
