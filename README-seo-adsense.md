# SEO / Google AdSense 設定ガイド

## 1. まずドメインを決めて置換する

`index.html`・`privacy-policy.html`・`robots.txt`・`sitemap.xml` の中に
`REPLACE_WITH_YOUR_DOMAIN` というプレースホルダーが入っています。
GitHub Pages で公開する場合、実際のURLは例えば

```
https://あなたのユーザー名.github.io/リポジトリ名/
```

になります。公開URLが決まったら、上記4ファイル内の
`REPLACE_WITH_YOUR_DOMAIN` をすべてそのURL（ドメイン部分）に
置き換えてください。エディタの「検索と置換」で一括変換できます。

## 2. SEO（検索対策）として組み込んだもの

- **メタディスクリプション / OGP / Twitter Card** — SNSでシェアされた
  ときや検索結果に、サイトの説明と `og-image.png`（同梱の画像）が
  表示されるようにしています。
- **JSON-LD構造化データ**（`TouristDestination`）— Googleがサイトの
  内容を「観光地」として理解しやすくなります。
- **hreflang（en / ja）** — 英語・日本語両方の内容があることを
  検索エンジンに伝えます。ただし今回のサイトは1つのURLの中で
  JavaScriptにより表示言語を切り替える構成のため、完全な多言語SEOと
  しては簡易的なものです。より本格的に日本語検索での上位表示を
  狙う場合は、`index.html`（英語）と `index.ja.html`（日本語）のように
  **URLを分ける**構成にすると、Google側でより正確に評価されやすく
  なります。必要であれば、そちらの構成へのリライトも対応できます。
- **robots.txt / sitemap.xml** — 検索エンジンに全ページのクロールを
  許可し、サイトマップの場所を伝えます。
- **favicon.svg** — ブラウザタブや検索結果に表示される小さなアイコン。
- **「最新情報」欄** — 毎月自動更新される新着情報は、検索エンジンに
  「このサイトは更新され続けている」という鮮度シグナルを与えます。

### 公開後にやっておくと良いこと
- **Google Search Console** にサイトを登録し、`sitemap.xml` を送信する。
- ページ内の見出し（`<h1>`→`<h2>`の構造）は既に整理済みなので、
  今後コンテンツを追加する際もこの階層を崩さないようにする。

## 3. Google AdSense

### 組み込んだもの
- `<head>` 内のAdSense読み込みスクリプト（`ca-pub-XXXXXXXXXXXXXXXX`
  の部分はプレースホルダー）
- 本文中に広告枠を2箇所（`<ins class="adsbygoogle">`）
- ルート直下に置く `ads.txt`（`pub-XXXXXXXXXXXXXXXX` はプレースホルダー）
- `privacy-policy.html`（AdSense審査・各種広告ポリシーで必須）
- ページ下部に、Cookie利用についての簡易バナー

### 設定手順
1. [Google AdSense](https://www.google.com/adsense/) にサイトのURLで
   申し込み、審査を申請します（審査には、ある程度のオリジナルコンテンツ量と
   プライバシーポリシーの掲載が必要です。今回のサイトには両方入っています）。
2. 承認されると、パブリッシャーID（`ca-pub-` から始まる文字列）が
   発行されます。
3. `index.html` 内の **すべての** `ca-pub-XXXXXXXXXXXXXXXX` を、
   発行された実際のIDに置き換えます。
4. `ads.txt` 内の `pub-XXXXXXXXXXXXXXXX` も同じIDに置き換え、
   サイトのルート（`https://あなたのドメイン/ads.txt`）で
   アクセスできる状態にします。
5. AdSense管理画面で広告ユニットを作成し、発行された
   `data-ad-slot` の値を `index.html` 内の該当箇所
   （`XXXXXXXXXX` / `YYYYYYYYYY` の部分）に置き換えます。

### 注意点（重要）
- **審査が通るまで広告は表示されません。** プレースホルダーのままでも
  サイトの表示自体は壊れません。
- **EU/EEA/英国からの訪問者がいる場合**、Googleの「EUユーザー同意
  ポリシー」により、パーソナライズ広告の表示前にGoogle認定の同意管理
  プラットフォーム（CMP）を使った同意取得が必要です。今回入れた
  Cookie通知バナーは簡易的な案内にとどまるため、本格的に運用する
  場合は正式なCMPの導入を検討してください。
- 広告枠の数・位置は、AdSenseのポリシー（コンテンツ量に対して広告が
  多すぎないこと、誤クリックを誘発する配置をしないことなど）を
  意識して控えめに設定しています。増やす場合もポリシーの範囲内で
  調整してください。
